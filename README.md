# homebrew-tap

Homebrew tap for [makit](https://github.com/nicholas-hoult/makit), a native manager for local Claude Code and Codex sessions.

```bash
brew install --cask nicholas-hoult/tap/makit
```

The cask is updated automatically after each makit release. makit is not signed or notarized yet, so the cask removes the quarantine flag after installing; see the makit README for details.
